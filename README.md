# 전문성 자산화 실험 (expertise-research)

한 사람이 경력에서 쌓은 판단 기준을 글과 AI로 옮기는 방법을 시험한 기록입니다. WorkCore 문병용(Brad Moon)이 자기 기록으로 먼저 시험하고 있습니다. 설명과 연구 질문은 https://workcore.io/research 에 있습니다.

## 들어 있는 것

- example/2 위키/ : 질문 30개 인터뷰와 본인 글 5편으로 만든 위키 66쪽 (판단기준 26, 경험 11, 개념 12, 영향받은 생각 5, 원천요약 12)
- example/3 확인/ : 실제 상황 질문으로 위키의 답을 본인이 판정한 기록
- example/1 원천/ : 본인 뉴스레터 글 5편, 인터뷰 원문 5회(질문 1~5번만 질문 문장 공개)
- docs/method.md : 실험 설계와 방법
- docs/literature.md : 읽고 있는 문헌 34편 (서지와 DOI)
- CHANGELOG.md : 날짜별 실험 기록
- tools/ : 위키 파일로 대시보드 화면을 만드는 프로그램. 「Brad에게 묻기」와 「질문함」 화면은 별도 서버가 필요해 이 예제에서는 동작하지 않습니다.

## 들어 있지 않은 것

- 오래 쌓은 기록으로 만든 큰 위키(실험 1)의 원본
- 질문 30개 전체 목록, 위키를 만드는 스킬
- 이력서와 경력기술서 원문
- 질문 30개 전체 목록은 연구 목적으로 필요하시면 hello@workcore.io로 요청해 주세요.
- 예제의 연락처는 지웠고, 사람 이름과 함께 일한 회사 이름은 역할로 바꿨습니다. 제가 다닌 회사 이름은 소개 쪽에 공개한 대로 두었습니다.
- 공개 예제는 민감한 표현 일부를 바꾸거나 뺀 인터뷰로 같은 방법을 한 번 더 돌린 사본입니다. 그래서 위키가 66쪽(판단 기준 26쪽)이고, 실험에 쓴 위키(72쪽, 판단 기준 29쪽)와 다릅니다. 같은 방법을 두 번 돌리면 판단 기준 수가 달라집니다(29개와 25개. 예제는 확인 뒤 1개를 더해 26개).

## 읽는 법

위키의 쪽마다 맨 아래 「출처」가 있습니다. 출처는 1 원천/의 파일과 인터뷰 질문 번호입니다. 판단기준 쪽에서 시작해 연결된 경험 쪽으로 따라가면 됩니다.

## 결과에 대해

두 위키를 견준 결과는 학술지 투고를 준비하고 있어 이 저장소에 싣지 않습니다. 실험하며 바뀐 생각은 뉴스레터 「일의 본질」(https://newsletter.workcore.io)에 씁니다.
