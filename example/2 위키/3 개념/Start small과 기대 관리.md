# Start small과 기대 관리
- 종류: 개념 · 갱신: 2026-11-15

## 본인이 쓰는 말과 그 뜻
- start small: 완벽하게 만든 뒤가 아니라 일단 작게 시작하는 것이다: "지금 다시 한다면 목을 걸고 일단 start small했을거야" (인터뷰 1회 5번)
- Expectation mgmt: 중간에 윗사람의 기대를 관리하며 여는 것이다: "그걸 중간에 Expectation mgmt하면서 오픈했어야 했어." (인터뷰 1회 5번)
